## Формат ввода.
- Вводится выражение, записанное в обратной польской нотации.
- В записи могут присутствовать круглые скобки, в том числе вложенные.
- Для записи унарного минуса используется символ "~".
- Для записи унарного плюса используется символ "$".
- Между числами и операторами, а также между любыми двумя операторами должно быть не менее одного пробела.
- В выражении могут присутствовать целые и действительные числа.
- Вводимые операнды больше или равны нулю, унарный минус - отдельная операция.
- Действительные числа записываются через точку.


## Алгоритм.
**1. Обработка скобок:**

Вводимая пользователем строка преобразуется в рекурсивный вложенный список из строк и списков-вложений.
Каждая пара скобок - новое вложение, между скобками и вне их - строки.


**2. Преобразование полученного списка:**

Строки в полученном списке разбиваются на операторы и операнды, операндам присваивается тип int или float.


**3. Вычисление:**

Элементы списка читаются слева направо. Числа кладутся в стек, операторы извлекают
аргументы из стека и кладут результат обратно, для вложений рекурсивно вычисляется результат вложенного выражения и кладётся в стек.


## Допущения.
- Унарный минус гарантированно является операцией, а не частью числа.
- Действительные числа записываются через точку.
- Между любой парой операнд-оператор или парой из двух операторов гарантированно есть хотя бы один пробел.
- При неправильном расположении скобок и неверном количестве или порядке операндов/операторов вызывается CalcError.
- При делении на ноль вызывается ZeroDivisionError.
- При невозможности разделить входную строку на операнды и оператоpы (лишние символы, отсутствие пробелов) вызывается SyntaxError.
